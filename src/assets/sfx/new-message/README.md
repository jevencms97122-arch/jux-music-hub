# SFX — Nouveau message

Dépose ici tes fichiers son (`.mp3`, `.wav`, `.ogg`) pour les notifications de nouveau message.

Chaque fichier ajouté apparaît automatiquement dans le sélecteur de l'app
(Profil → Paramètres du Compte → Son de notification) — pas besoin de modifier le code,
juste rebuild l'app après avoir ajouté un fichier.
